# Sample document rights and provenance

`Attention.pdf` and `LLM.pdf` predate the bug-fix review. This repository does not
currently establish their acquisition source or redistribution permission.
The project's MIT code license does not relicense these documents. Verify their
provenance and permitted use before republishing them or using their contents
with an external provider. This note records the unresolved gap; it does not
assert that permission has been obtained.

For a demonstration, use your own text PDFs or documents whose license and
sharing permissions you have checked. Record title, author, original URL,
license/permission, retrieval date, and expected evidence pages alongside your
real evaluation dataset. Do not commit confidential documents.
